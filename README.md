# Brand System

Repositório central de sistemas de marca da Complan e suas operações.

## Estrutura

Cada marca possui uma pasta própria com identidade, tokens, regras de uso, referências e decisões de design.

- `EDD-Brand-System/` - Escola de Dança Louvor na Terra
- outras marcas serão adicionadas futuramente

## Princípio de governança

O GitHub guarda regras consolidadas, índices e decisões. Bibliotecas vivas de mídia permanecem nas fontes originais (como Google Drive) e devem ser consultadas de forma incremental, sem reprocessar arquivos já analisados quando não houver mudança.
