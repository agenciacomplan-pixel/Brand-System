# Web - EDD

## Estado atual

A EDD ainda não possui repertório específico de sites aprovados além do site atual `https://dancalouvornaterra.com.br/`.

O site atual deve ser usado provisoriamente para compreender conteúdo, oferta, estrutura de negócio e informações existentes. Não tratá-lo como padrão visual definitivo.

## Princípios

- O site deve compartilhar o mesmo núcleo visual da EDD, sem parecer um post ampliado.
- Criar sistema próprio de componentes, grids, espaçamentos e estados interativos.
- Priorizar responsividade mobile-first, acessibilidade e legibilidade.
- Fotografia real deve ter papel relevante quando representar professores, comunidade ou experiência.
- CTA deve ser evidente sem competir com todos os demais elementos.
- Preservar hierarquia clara entre hero, prova, conteúdo, oferta, depoimentos, FAQ e conversão quando essas seções forem pertinentes.

## Evolução

Quando referências web externas forem adicionadas ao Drive:

1. Analisar somente as novas referências.
2. Extrair princípios de navegação, composição, tipografia, animação, cards e uso de fotografia.
3. Não copiar sites literalmente.
4. Atualizar esta guideline apenas quando houver decisão ou padrão consistente.
